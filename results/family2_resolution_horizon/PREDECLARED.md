# PREDECLARED — Family 2: resolution × horizon hold-out

Written **2026-09-11**, before this family’s stability screen, geometry measurement,
smoke fit, or any full-run fit. This file is binding and is not changed after an
outcome is observed. Failures and incomplete cells remain failures and incomplete
cells; thresholds are never tuned after launch.

The validated source harness is
`pde_restart/family1_rerun/run_family1_rerun.py`, which
imports `family1_second_pairs/run_family1.py`, which in turn imports the shipped
`pkg_scratch/scripts/baseline/run_baseline.py` and `timing_probe.py`. Family 1’s
`RESULT.md` reports **VALIDATION PASS** on all four binding P1 checks. This family
imports that chain and does not copy-edit it. `recovery/` and `pkg_scratch/` are
read-only.

## 1. Question and fixed pair

Does the banked P1 support-broadening result persist when the spatial resolution and
the duration of the state-producing handoff are held out?

- Pair: **P1 diffusion / Fisher–KPP** only.
- Diffusion: diffusivity `0.01`.
- Fisher–KPP: diffusivity `0.0`, reactivity `1.0`.
- Periodic 1-D domain of extent `1.0`; ETDRK order 2; dealiasing `2/3`; 16 circle
  points; circle radius `1.0`.
- `dt = 0.01` at every resolution and exactly 100 ETDRK2 steps per physical leg.
- Resolutions: `N in {128, 256, 512}`.
- Horizons: `L in {1, 2, 3}` legs.

No timestep may be changed after the stability result. If `N=512` fails the screen
at `dt=0.01`, every `N=512` cell is an **apparatus stop**, not a failure or pass, and
the other resolutions continue.

## 2. Horizon and estimand

The package’s fitted primitive remains the `k=10` diffusion solution operator: one
FNO application advances `0.10` physical time. Horizon changes only the state handed
to that primitive:

1. Generate the switch cohort exactly as `run_baseline.py`, from narrow ICs at
   `MASTER_SEED+8`.
2. For horizon `L`, advance those ICs under Fisher–KPP for `100*L` ETDRK2 steps.
   The resulting state is the end of the final handoff leg.
3. `e_off` is the median relative L2 error of one fitted `k=10` diffusion application
   at that state, against ten exact diffusion steps from that same state.
4. `e_on` is unchanged from `run_baseline.py`: narrow ICs at `MASTER_SEED+7`, with
   the median relative L2 error against ten exact diffusion steps.
5. Per fitted model, `R = e_off/e_on`.

Thus `(N=256,L=1)` is the replication anchor, and every horizon retains the package’s
off-support/on-support definition. This is not an autoregressive FNO rollout test.

## 3. Data and model (fixed)

At each `N`, initial conditions are generated by the package routine, changing only
its grid length:

`clip(offset_i + 0.175 * RandomTruncatedFourierSeries(cutoff=5, std_one=True), 0, 1)`.

- Narrow offsets: `(0.4865, 0.5171)`.
- Broad offsets: `(0.4865, 0.7258)`.
- Training: 640 diffusion trajectories, 101 frames each, RNG `MASTER_SEED+1`.
- Evaluation: 256 units per cohort.
- `MASTER_SEED = 20260905`.
- FNO: 16 modes at every `N`, width 64, 4 layers, projection width 128, float32.
- Training pairs: all `t -> t+10` pairs (91 per trajectory).
- Optimizer and schedule: the shipped hand-written Adam, batch 64, 8000 steps,
  cosine learning rate from `1e-3` to `1e-5`.
- Seeds: `0..9`; FNO initialization uses `seed`, batch draws use `seed+9999`.

The training corpus and fitted model do not depend on `L`. Therefore a model is fit
once for each `(N, condition, seed)` — 60 unique fits — and the exact same checkpoint
is evaluated at all three horizons. Re-fitting an identical deterministic model for
each horizon would create duplicate weights, not new experimental units. Each of the
18 cells still receives ten per-seed JSON records at
`results/N{N}_L{L}_{condition}/seed{k}.json`.

## 4. Stability and support geometry

Before training, each resolution is checked using the rules in the shipped
`screen_stability.py`:

- both one-leg orderings (diffusion then Fisher–KPP, and reverse) must run and be
  finite;
- maximum absolute composed value must not exceed 10 times the initial maximum;
- advective CFL is `0` for P1 and therefore must be at most `1`;
- endpoint order dependence must be at least `1e-6`.

The requested Fisher–KPP switch rollout is additionally required to be finite and
below the same 10× growth bound at every `L in {1,2,3}`. The screen uses the package
screen cohort (32 units, seed `20260905`) and float64, as `screen_stability.py` does.
For every `N`, record `dx=1/N` and the diagnostic diffusion number
`0.01*dt/dx^2`; ETDRK treats the linear diffusion term exponentially, so this number
is reported rather than used as an extra post-hoc gate.

Support uses `run_baseline.py`’s statistic: the interval of spatial means over all
101 frames of all 640 narrow diffusion training trajectories. At `(N,L)`, switch
support is the interval of spatial means at the end of the `100L`-step Fisher–KPP
handoff. Overlap is
`max(0, min(training_hi,switch_hi)-max(training_lo,switch_lo))`; signed support gap
is `switch_lo-training_hi`.

## 5. Primary gates

- **G1 — zero overlap:** overlap must equal exactly `0.0` at every completed `(N,L)`.
- **P3 — repair:** at every completed `(N,L)`,
  `median(R_broad) <= 0.25 * median(R_narrow)` across seeds `0..9`.
- **MONOTONE:** over the nine `(N,L)` cells, take `x = support gap` and
  `y = log(median R_narrow)`. Spearman correlation is the Pearson correlation of
  average ranks (average ranks for ties) and must be at least `0.5`. It is computed
  descriptively on any partial set with at least two distinct ranks, but can pass as
  a gate only when all nine cells are complete.

The **family verdict is PASS** iff all nine primary cells are complete, G1 and P3 hold
in every cell, MONOTONE holds, and the negative control below is clean. An apparatus
stop or 12-hour stop makes the family verdict **INCOMPLETE**, never PASS. Otherwise a
completed family is FAIL if any gate fails.

## 6. Negative control

At `N=256`, `L=1`, use diffusion / constant-velocity advection. Advection velocity is
`0.25`, the stability-screen value (advective CFL `0.64`), and the pair’s two exact
Fourier-diagonal operators should commute to solver precision. The integrity check is
maximum relative endpoint order contrast `< 1e-12` in float64.

Use seeds `0,1,2` and the same already-fitted `N=256` narrow and broad diffusion
models. Construct switch states by 100 advection steps from the `MASTER_SEED+8`
cohort, then compute `R` by the same one-application definition above. For each seed,
form the paired quotient `Q_s = R_broad,s/R_narrow,s`. The control is **clean iff
1.0 lies in the inclusive seed range `[min Q_s, max Q_s]`**. This operationalizes
“must not differ from 1 beyond the seed range” before the values are seen. The median
and full range are reported; no significance claim is made from three seeds.

## 7. Order, stopping, and reporting

Cell priority is fixed:

1. `(256,1)` replication anchor;
2. `(128,1)`, `(512,1)` resolution sweep;
3. `(256,2)`, `(256,3)` horizon sweep;
4. `(128,2)`, `(128,3)`, `(512,2)`, `(512,3)` corners.

The negative control runs immediately after the anchor. Existing valid per-seed files
and checkpoints are resumed, never silently overwritten. After each cell, update
`RESULT.json` and `RESULT.md`. If elapsed wall time exceeds 12 hours, finish the
current cell, checkpoint and aggregate it, mark all remaining cells incomplete, and
stop. `RESULT.md` begins with the honest verdict and includes an `N × L` table of
`median R_narrow / median R_broad / ratio`, seed ranges, all gates, the negative
control, and one candid interpretive paragraph. Artifacts must remain below 3 GB.

The one-seed smoke is explicitly non-inferential: seed 0, both conditions, anchor
cell only, written under `smoke/` with separate checkpoints. It validates the full
train/checkpoint/reload/evaluate/JSON path but cannot change any gate or threshold.
